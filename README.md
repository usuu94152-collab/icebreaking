# 손가락 프레임 웹툰 필터 (아이스브레이킹용)

웹캠 앞에서 양손 **엄지·검지로 ㄱ ㄴ 모양 프레임**을 만들면, 그 프레임 안쪽만 실시간으로 웹툰·스케치·팝아트·네온·열화상 등으로 바뀌는 브라우저 앱입니다.
한 손을 뒤집으면 사각형 대신 **삼각형 두 개**가 되고, 한 손으로 손가락을 펴면 **인사 자막**이 나옵니다.
강의 시작할 때 화면에 띄워 두고 강사나 학생이 직접 해 보는 용도로 만들었습니다.

- 손 인식: MediaPipe Hand Landmarker (브라우저에서 실행, 모델 파일 포함 → **인터넷 없어도 동작**)
- 스타일 변환: WebGL 셰이더 (일반 노트북 내장 그래픽으로도 실시간)

## 실행 방법

카메라는 보안상 `https://` 주소나 `http://localhost` 에서만 켜집니다. `index.html` 을 더블클릭해서 여는 방식(`file://`)은 동작하지 않아요.

### 방법 1. 로컬에서 실행 (강의실 인터넷이 불안할 때 추천)

1. 이 레포를 내려받습니다 (GitHub → Code → Download ZIP 후 압축 해제).
2. 실행 스크립트를 더블클릭합니다.
   - Windows: `start.bat`
   - macOS: `start.command`
3. 브라우저가 `http://localhost:8000` 으로 열리면 카메라 권한을 **허용**합니다.

> 두 스크립트 모두 Python 이 필요합니다 (`serve.py` 를 실행합니다). 터미널에서 `python serve.py` 로 직접 켜도 됩니다.

### 방법 2. GitHub Pages

레포 Settings → Pages 에서 이 브랜치를 배포하면 `https://<아이디>.github.io/icebreaking/` 주소로 바로 열 수 있습니다.

**브라우저는 최신 Chrome 이나 Edge 를 권장합니다.**

## 사용법

| 동작 | 방법 |
|---|---|
| 사각형 프레임 | 양손 검지는 위로, 엄지는 안쪽으로 펴서 ㄱ ㄴ 모양 |
| 삼각형 두 개 | 한 손(또는 두 손)을 뒤집어서 검지는 아래로, 엄지는 위쪽 안쪽으로 |
| 스타일 바꾸기 | 하단 버튼 또는 `1` 웹툰 · `2` 스케치 · `3` 픽셀 · `4` 팝아트 · `5` 네온 · `6` 열화상 |
| 좌우 반전 | `M` (기본값: 거울 모드) |
| 프레임 테두리 | `B` |
| 인사 자막 켜기/끄기 | `G` (기본: 켜짐) |
| 전체화면 | `F` |
| 캡처 저장 | `S` (PNG로 다운로드) |
| 툴바 숨기기 | `H` (마우스를 3초간 안 움직이면 자동으로 숨겨짐) |
| 디버그 표시 | `D` (손 랜드마크, FPS, 단계별 처리 시간) |

카메라가 여러 대면 툴바에 카메라 선택 메뉴가 나타납니다.

### 진행 팁

- 손끝을 입 앞에 모았다가 천천히 벌리면, 작은 그림 조각이 점점 커지는 연출이 됩니다.
- 프레임을 만든 채로 한 손을 돌려 뒤집으면 사각형이 ⋈ 모양 삼각형 두 개로 바뀝니다.
- 프로젝터 화면에 띄울 때는 거울 모드(기본값)가 자연스럽습니다.
- 손이 화면에 잘 보이도록 밝은 곳에서, 웹캠에서 1m 정도 떨어지면 인식이 잘 됩니다.

## 인사 자막 (`G` 키로 켜고 끄기)

**한 손**을 들고 손가락을 펴는 개수에 따라 화면 아래에 큰 자막이 나옵니다.
자막은 신문·잡지에서 글자를 한 자씩 오려 붙인 **랜섬 노트 스타일**이고, 글자가 한 장씩 탁탁 붙으며 나타납니다.

| 펴는 손가락 | 자막 |
|---|---|
| 검지 | 안녕하세요 |
| 검지 + 중지 | 저는 오늘 여러분들과 |
| 검지 + 중지 + 약지 | AI에 대해 이야기 할 |
| 검지 + 중지 + 약지 + 새끼 | 체육교사 유성욱입니다 |
| 다섯 손가락 | 만나뵙게 되어 반갑습니다 |

- 손바닥이 카메라를 보게 들고, 검지부터 차례로 펴면 됩니다.
- 1~4단계에서는 엄지를 **손바닥 쪽으로 접어** 주세요. 엄지를 검지 옆에 붙이기만 하면 5단계로 인식될 수 있습니다.
- 5단계는 엄지를 옆으로 벌리면 됩니다.
- 잘 안 잡히면 `D` 키를 눌러 보세요. 손 옆에 `손가락 N · 엄지 0.xx` 가 표시됩니다. 엄지 값이 0.15 보다 크면 엄지를 편 것으로 봅니다
  (기준값은 `js/greeting.js` 의 `THUMB_OUT`).
- 손가락 모양을 0.2초 정도 유지하면 자막이 바뀝니다. 주먹을 쥐거나 손을 내리면 잠시 뒤 사라집니다.
- 양손으로 프레임을 만들면 자막은 숨겨지고 프레임 효과가 나옵니다.
- 문구는 `js/greeting.js` 맨 위의 `GREETINGS` 배열에서 바꿀 수 있습니다.
  같은 문장은 항상 같은 배치로 나오고, 문구를 바꾸면 배치도 새로 정해집니다.
- 글꼴 9종(Black Han Sans, 도현, 나눔명조, 나눔펜, 구기, 연성, 주아, 송명, 동해독도)이 `fonts/` 에 들어 있어
  인터넷 없이도 같은 모양으로 나옵니다. 자주 쓰는 한글 2,350자만 담아서, 아주 드문 글자는 기본 글꼴로 보일 수 있습니다.

## 스타일

| 키 | 스타일 | 설명 |
|---|---|---|
| `1` | 웹툰 | 피부를 매끈하게, 밝은 색감 + 만화 외곽선 |
| `2` | 스케치 | 종이 위 연필 드로잉 |
| `3` | 픽셀 | 8비트 게임 도트 |
| `4` | 팝아트 | 미국 만화책 스타일: 망점(하프톤) + 굵은 먹선 |
| `5` | 네온 | 어두운 화면에 윤곽선이 네온색으로 빛나고 스캔라인이 지나감 |
| `6` | 열화상 | 사람(피부)은 뜨겁게, 배경은 차갑게 보이는 열화상 카메라 |

## 구조

```
index.html          화면 구성
css/style.css       스타일
js/main.js          카메라, 렌더 루프, 단축키
js/hands.js         MediaPipe 손 인식 → 프레임 다각형 계산 (사각형 / 삼각형 두 개, One Euro 필터로 떨림 보정)
js/renderer.js      WebGL2 셰이더: 스타일 6종 + 프레임 안쪽만 합성
js/greeting.js      인사 자막: 손가락 개수 세기 + 문구
serve.py            로컬 서버 (start.bat / start.command 가 실행)
fonts/              랜섬 노트 자막용 한글 글꼴 9종 (SIL OFL 1.1, fonts/OFL.txt)
vendor/mediapipe/   MediaPipe Tasks Vision 0.10.14 (Apache-2.0)
models/             MediaPipe 손 인식 모델
```

프레임은 두 손의 검지 끝·엄지 끝(랜드마크 8, 4번) 네 점으로 만듭니다.
검지 끝이 엄지 끝보다 아래에 있는 손을 "뒤집힌 손"으로 보고, 한 손이라도 뒤집히면
각 손의 두 점과 네 점의 중심을 이어 삼각형 두 개를 만듭니다.
